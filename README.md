# TaskBoard – Examen Programación Web

Esta es una aplicación de lista de tareas creada con React y Redux.

**Funciones:**
- Agregar tareas nuevas
- Marcar tareas como completadas
- Eliminar tareas
- Las tareas completadas se muestran al final de la lista
- Contador global de tareas completadas

El estado se maneja completamente con Redux, usando dispatch y un reducer con las acciones:
ADD_TASK, TOGGLE_TASK y DELETE_TASK.

Este proyecto fue desarrollado como parte de mi examen parcial.
